Pāṇini's Perfect Alphabet:
the Śivasūtra Optimality Theorem, Machine-Checked

A 4th-century-BCE data structure, a 2004 optimality proof, and the first Lean formalization of any part of Sanskrit's greatest grammar.

1.The problem Pāṇini had

Around the 4th century BCE, Pāṇini wrote a complete grammar of Sanskrit in roughly 4,000 terse rules — the Aṣṭādhyāyī, often called the first generative grammar in history. His rules constantly need to say things like "after any vowel…" or "replace any voiced stop…". Writing out the sound lists every time would bloat the grammar enormously, and the whole work was designed to be memorized.

His solution: before the grammar proper, list all sounds of Sanskrit once, in 14 short lines (the Śivasūtras), each line ending in a dummy marker letter. Then any contiguous stretch of that list can be named by just two letters: a start sound plus a marker. Such a name is called a pratyāhāra. aC = "from a to marker C" = all nine vowels. haL = "from h to marker L" = all 33 consonants.

3.What "optimal" means

The trick only works if the sounds are ordered so that every class the grammar needs — Pāṇini uses 43 such pratyāhāras — happens to sit contiguously. That is a hard combinatorial constraint. Two "tricks" cost extra:

  • every marker is one more thing to memorize — Pāṇini uses 14;
  • a duplicated sound is a wart — Pāṇini repeats exactly one sound, h.

In 2004 the logician Wiebke Petersen proved (on paper) that this is optimal: among all conceivable orderings of Sanskrit's sounds that make his 43 classes contiguous, none duplicates fewer sounds; and given the minimal single duplication, none uses fewer markers. The repository this page ships with mechanizes that theorem in the Lean 4 proof assistant — the first machine-checked result about Pāṇini's grammar in any theorem prover.

A discovery along the way. The first attempt to state the theorem used a naive reading where a pratyāhāra whose marker is missing just runs to the end of the list. Under that reading the theorem is false — the kernel found that deleting Pāṇini's final marker L leaves all 43 classes intact with only 13 markers! The fix is the traditional reading: a pratyāhāra's marker must actually occur. Under it, the deletion breaks the class raL — press the raL button above and note how its span needs the trailing h L. The kernel thus certifies that Pāṇini's 14th sūtra is load-bearing.

5.Why h, of all sounds?

Look at the explorer again: h lives at line 5 with y v r (they behave alike in some rules — class aṬ), but it is also an obstruent that patterns with ś ṣ s in others (class śaL, and the big L-classes like raL, vaL, jhaL). No single position can sit in both neighborhoods — the three-way independence with v and l makes that a theorem, not a heuristic. So Pāṇini pays the minimum possible price: one extra h at the very end.
