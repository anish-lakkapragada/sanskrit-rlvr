छन्दःशास्त्रम्

Fibonacci, Five Hundred Years Early:
the Rhythms of Sanskrit Verse

An interactive tour of a theorem from ancient Indian prosody — now machine-checked in the Lean 4 proof assistant.

1.Two kinds of syllable

Sanskrit poetry doesn't count syllables the way English verse does — it times them. Every syllable is either light (laghu, "ka") lasting one beat, or heavy (guru, "kā") lasting two. A beat is called a mātrā. A line of verse is just a sequence of shorts and longs — a rhythm, like Morse code.

1 laghu — light, 1 mātrā 2 guru — heavy, 2 mātrās

Around the 3rd century BCE, Piṅgala wrote the Chandaḥśāstra, a treatise that classifies all these rhythms. One family of meters — the mātrā-vṛtta — fixes only the total number of beats, leaving the syllable count free. Which raises a combinatorial question a modern mathematician would love:

How many different rhythms take exactly n beats?

2.Try it — every rhythm of n beats

Rhythm counter (click a pattern to hear it)

Move the slider and watch the counts: 1, 2, 3, 5, 8, 13, 21, 34… — the Fibonacci numbers. The count for n beats is the Fibonacci number fib(n+1).

3.Why? The last syllable tells all

Virahāṅka's argument (c. 700 CE) is two sentences. A rhythm of n beats ends either in a 1 — leaving a rhythm of n−1 beats in front of it — or in a 2 — leaving n−2. And every rhythm arises exactly once this way. So:

V(n) = V(n−1) + V(n−2),   V(0) = 1, V(1) = 1

That is the Fibonacci recursion, stated for rhythms around 700 CE by Virahāṅka and spelled out by Gopāla and Hemacandra (c. 1150) — before Leonardo of Pisa ("Fibonacci") published Liber Abaci in 1202. In the widget above, patterns are grouped by their first syllable: green-first patterns biject with the (n−1)-beat rhythms, maroon-first with the (n−2)-beat ones.

4.What the machine actually checked

It's easy to prove the recurrence; the real theorem is about the set of rhythms. The Lean development (panini/Panini/Pingala.lean) defines syllables and weight, builds Virahāṅka's enumeration, and proves four things about it:

Lean theoremIn plain words
mem_patternsThe enumeration is sound and complete: it lists a pattern if and only if that pattern's total weight is n. Nothing wrong gets in; nothing right is missed.
nodup_patternsNo rhythm is listed twice.
card_matra_patternsTherefore the set of weight-n rhythms has exactly fib(n+1) elements.
card_varna_patternsBonus (Piṅgala's prastāra): rhythms with a fixed syllable count n number 2n — his light/heavy expansions are a binary numeral system, two millennia before Leibniz.
-- the enumeration and the two headline statements
def patterns : ℕ → List (List Syllable)
  | 0     => [[]]
  | 1     => [[laghu]]
  | (n+2) => (patterns (n+1)).map (laghu :: ·) ++ (patterns n).map (guru :: ·)

theorem mem_patterns : p ∈ patterns n ↔ weight p = n

theorem card_matra_patterns (n : ℕ) :
    ((patterns n).toFinset).card = Nat.fib (n + 1)

Every proof is checked down to Lean's logical kernel — no sorry, no trust in the prose above. The counting you did with the slider is, in effect, what the kernel verified once and for all, for every n.
