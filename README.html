अल्पाच्तरम् — किं वर्णानां दौर्लभ्यम्?

Was There a Dearth of Letters?
The Doubled Ṇ of the Śivasūtras

Pāṇini re-used exactly one marker letter, and Patañjali demanded to know why. The Lean kernel now certifies what the re-use costs: an ambiguity that no uniform convention can resolve — because Pāṇini's own grammar needs both readings.

1.The complaint, twenty-two centuries old

Pāṇini's grammar of Sanskrit (4th c. BCE) opens with the Śivasūtras: all the sounds of the language in 14 short lines, each closed by a dummy marker letter (dark below). A sound plus a later marker names the stretch between them — a pratyāhāra — and these are the grammar's names for its sound classes. Thirteen of the fourteen markers are distinct. But line 1 and line 6 both end in Ṇ (highlighted orange below). It is the only re-used marker in the system.

Kātyāyana and Patañjali (the Mahābhāṣya, c. 150 BCE) pressed the point: why re-use Ṇ at all — was there a dearth of letters? And which Ṇ does a pratyāhāra like aṆ mean?

The question is sharp because the two candidate meanings are wildly different: read to the first Ṇ and aṆ = {a, i, u}; read to the second and it also swallows the other vowels and h y v r l. And the tradition records — and rule 1.1.69 vs. rule 8.4.57 confirm — that the Aṣṭādhyāyī uses both readings. This page lets you reproduce, live, what the Lean kernel proved about that situation.

3.No uniform convention survives

Could Pāṇini simply have declared "always the nearest Ṇ" (the natural default) or "always the farthest"? No — and this is the theorem. The grammar's 43 attested classes include both aṆ₁ = {a, i, u} and aṆ₂ = the vowels + h y v r l. Each uniform convention loses one of them, with no rescue encoding anywhere in the alphabet:

4.What exactly was proved

The file panini/Panini/Ambiguity.lean models the Śivasūtras as recited — one and the same token Ṇ closing lines 1 and 6 — defines the near and far reading semantics, and proves five kernel-checked theorems:

-- exactly three pratyāhāras are ambiguous: aṆ, iṆ, uṆ
theorem ambiguous_pratyaharas_card : … = 3

-- the uniform conventions each lose an attested class
theorem nearest_convention_fails  : ¬ ∀ C ∈ paniniClasses, EncodesT shivasutrasR C
theorem farthest_convention_fails : ¬ ∀ C ∈ paniniClasses, EncodesF shivasutrasR C

-- Pāṇini's own usage needs both readings (1.1.69 vs the rest; iṆ in 8.3.57)
theorem both_readings_attested : pratyahara shivasutrasR a Ṇ = aṆ₁ ∧ pratyaharaF … = aṆ₂ ∧ …

-- but resolving rule by rule, all 43 attested classes are served
theorem mixed_reading_covers : ∀ C ∈ paniniClasses, EncodesT shivasutrasR C ∨ EncodesF shivasutrasR C
Patañjali's complaint, as mathematics. The re-used Ṇ saves one letter of recitation. The price, now kernel-certified: the metalanguage stops being context-free — three abbreviations have no fixed meaning, no uniform disambiguation rule is consistent with the grammar's own usage, and every occurrence of aṆ/iṆ must be resolved rule by rule (which is precisely what the commentarial tradition does). Economy of symbols was traded for context-dependence of interpretation — a trade-off any programming-language designer will recognize.

The two Lean refutation theorems witness aṆ₂ and aṆ₁ respectively; the tester above also shows iṆ dying under the nearest convention.
