Coverage and how the answers are verified
The generator changes exactly one coordinate for the same dictionary dhātu. It compares the resulting trace against every target derivation and finds the first prefix that no target path can match. Gold includes every complete target continuation compatible with the earlier correct prefix. Grading parses the JSON, normalizes Unicode, and compares the full answer against this set.
We retain changed term states in VP order, omit empty terms and consecutive duplicates, and preserve technical markers. Alternate paths may contain different numbers of checkpoints. These are engine-relative answers under VP 0.4.0, with existing source holds and a lossless transliteration check applied; this is not independent certification of all Sanskrit analyses.
Regenerate with .venv/bin/python benchmarks/correction/generate.py; verify with .venv/bin/python benchmarks/correction/verify.py. Task generation and verification make no paid model calls; model evaluation costs are reported separately.
