# Passive ciṇ discovery: source and contract review

The 46 proposed questions are eligible for a small discovery experiment. No concrete lexical, semantic, pada or variant blocker was found in this bounded review. This is rule-based certification with representative dictionary controls, not a claim that a primary text separately prints all 46 paradigms or that every historical edition agrees.

The panel uses the unchanged ordinary four-coordinate contract and renderer. Each input supplies a dictionary citation, class and meaning, then **Lun / Karmani / Prathama / Eka**. There is no added operation, prefix, dialect switch or chosen pada. The eight Curādi entries retain their ordinary intrinsic class formation; no independently selected causative meaning is introduced.

[Kāśikā 3.1.66](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/3/3.1.66.htm) prescribes ciṇ for cli in passive/impersonal use before the **ta** ending and directly exemplifies akāri and ahāri. The Nyāsa explains why the preceding active-rule optionality and prohibition do not carry into this rule. [6.4.104](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/6/6.4.104.htm) deletes the ending following ciṇ. Thus this is a passive third-person singular interaction, not generic aorist exposure. The independently reviewed Bhāve issue is outside this panel.

Passive [1.3.13](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/1/1.3.13.htm) fixes the middle endings; it does not add a fifth input choice. For all 46 tasks the unrestricted engine gold equals the union of explicit parasmaipada and ātmanepada derivations. Every accepted path contains both 3.1.66 and 6.4.104. Twelve same-entry controls changing only number, tense or voice lose 3.1.66, covering Divādi, Svādi, Kryādi and Curādi. These controls are offline checks and are not paid-panel model controls. One 10.0221 path omits the explicit 1.3.13 trace marker; its middle-ending selection, mandatory ciṇ path and full-pada union agree. Rule-marker presence alone is not treated as the entire validity proof.

[7.2.115](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/7/7.2.115.htm) supports the final-vowel grade, including śṝ → aśāri and mī → amāyi by subsequent vowel resolution. [6.4.24](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/6/6.4.24.htm) restricts nasal loss to k/ṅ-it contexts: bandh → abandhi therefore preserves n here. [6.4.51](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/6/6.4.51.htm) accounts for intrinsic ṇic deletion before non-iṭ ārdhadhātuka suffixes in the eight Curādi paths. The optional lengthening rule [6.4.93](https://sanskritdocuments.org/learning_tools/ashtadhyayi/vyakhya/6/6.4.93.htm) was checked separately; none of these tasks has the mit-shortening 6.4.92 context. No optional engine answer was removed. All current gold unions happen to contain one form; that fact alone is not offered as proof of complete variant coverage.

The lexical screen is the previously declared exact transitive-meaning allowlist, with shared policy21 and earlier local precautions. The selected meanings denote harming, cutting, breaking, binding, giving, taking, eating or abandoning; no new per-question interpretation chooses between transitive and intransitive readings. Representative primary Dhātupāṭha entries preserve dada/giving, hā/abandoning, mī/harming, Svādi kṛ/harming, vrasc/cutting, Tanādi ṣaṇu/giving, bandh/binding and Curādi śraṇ/giving. Their cached dictionary locations and hashes are recorded in the JSON audit. Distinct homonyms and inherited-prefix/sanādi entries remain governed by shared scope. The exact meaning list is a conservative supply screen, not an assertion that all other meanings are intransitive.
