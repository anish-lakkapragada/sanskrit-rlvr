# Finite spelling policy proposal for 1,800 questions

This is a pre-output proposal, not an adopted scoring policy. It binds the exact 1,800-question task hash and preserves every canonical VP answer. The rule generator is the unchanged helper reviewed for `ending-screen-01`; no new grammatical rule or iterative consonant-doubling closure is added.

The map contains 3,224 canonical task/form entries and 3,289 additional aliases across 1,193 tasks. All 1,250 retained tasks have exactly the same alias-policy items as their earlier proposal. The 13 representative controls cover all ten classes and all ten tenses.

Original-position final n/t/d doubling, the bounded postvocalic r/h condition, and eligible two-consonant clusters are handled with the same exclusions and aspirate-copy adjustment. All final n/t/d sites in this candidate follow vowels. There are 79 tasks with 122 flagged contexts involving pre-existing gemination or clusters outside the finite expansion. These flags are limitations of alias coverage, not evidence that the canonical task is invalid.

An independently written regular-expression reconstruction matched all 1,800 task maps. The scorer accepted all 6,513 canonical/alias task forms, routed 1,800 unlisted mutations to review, rejected cross-task and unknown-ID use, and did not normalize 90 final-n retroflex mutations or 226 triple-final-stop mutations into accepted answers. These checks verify the finite boundary; they do not independently certify the grammatical invalidity of every synthetic negative control.

Every usable unrecognized answer requires source adjudication before contributing to an error or benchmark-advancement claim, including answers on unflagged tasks. Keep canonical-only, predeclared-alias and later adjudicated scores separate. Apply any established source correction symmetrically to every affected task and model, preserving raw outputs and unresolved cases. No model outputs were inspected in constructing or checking this proposal.
