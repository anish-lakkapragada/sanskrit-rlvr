# VP-Bench: unscored 1,800-question proposal

Prepared 2026-10-07 Pacific / 2026-10-08 UTC. This is a separate, input-only proposal; it is not a scored benchmark, registered evaluation, or final release freeze.

The task remains a dictionary Sanskrit verbal root, identified by citation/class/meaning, plus the original four coordinates: lakara, prayoga, purusha and vacana. Every question here uses Kartari. No selected pada, prefix, or added sanadi operation is introduced. Intrinsic dictionary grammar still applies.

All 1,250 complete task objects from `candidate-1250-v2` are preserved exactly. The extension adds 286, 44 and 220 questions respectively, with no replacements. Retained task objects keep their historical panel and sampling metadata; the new manifest specifies the aggregate allocation. The 220 added broad families are chosen by the least current class load, with a seeded input-hash tie break. A single-thread integer solver then balances coordinates using no model outputs or expected success labels.

The final panel has all ten classes and ten tenses. Aorist accounts for 216 questions (12%); each other tense has 176. Each person and each number has exactly 600 questions. Curadi supplies 60%; the remaining class counts are Bhvadi 446, Divadi 87, Tudadi 81, Adadi 37, Kryadi 32, Rudhadi 13, Svadi 10, Juhotyadi 9 and Tanadi 5. This is a deliberate grammatical mixture, not uniform sampling of the entire four-dimensional universe.

The actual regenerated fresh supply was 1,119 short-adanta tuples across 14 families, 188 other-adanta aorist tuples across 21 families, and 68,827 broad tuples across 774 families. All four lexical holds and the exact declared Cada reading from v2 carry over unchanged. The generator checks complete VP canonical unions, prompt rendering, source filters, the master test split, and freshness. The 1,800 questions have zero overlap with historical public ordinary tuples, registered-job root families, or the strict training inventory's families, raw/rendered citations, coordinate tuples or prompts. Legacy dictionary-wide discovery had already inspected lexical families before the split, so this does not establish never-inspected lexical families.

At 1,800 independent Bernoulli observations, projected standard error is 0.780 percentage points at 87.5% and 0.934 points at 80.5%; it remains below one point throughout the 80–90% range. These are projections from the development rates, not scores on this candidate. They also are not 95% interval half-widths or evidence of below-one-point uncertainty on new root families. The dominant 52% stratum still has only 14 independent test families. Increasing its coordinate coverage does not resolve that bottleneck.

The accepted source reading and previous bounded lexical/rule reviews are inherited. Every form regenerates mechanically, but the 550 additional forms have not each received independent primary-source certification.
