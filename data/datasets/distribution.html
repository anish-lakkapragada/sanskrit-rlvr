74,193 inputs × 175 suffixes
= 12,983,775 attempts

धन + मतुप् → धनवत्
A derived stem meaning “possessing wealth.”

Across all 175 attempts per input: 25.745794% were exported, 74.254206% produced no form, and 0.000000% failed the output transliteration check.

Each input already includes its source-listed gender. There is no case or number multiplier: the target is a derived stem or a complete indeclinable.

What counts as a nominal input?

Both nominal families use the same 74,193 resolved stem–gender pairs in shared-nominal-stems.json. The dictionary normalization and VP representation filter have already been applied.

Each request preserves the stem, its basic/nyap interpretation, and its source gender. Gender can affect affix eligibility. It does not specify the gender of the resulting word.

MWlexnorm is the sole lexical source. Excluded raw headwords are not added back. Taddhitānta uses the documented VP compatibility patch for feminine inputs.
